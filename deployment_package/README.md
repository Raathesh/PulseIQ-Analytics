
# PulseIQ Analytics – Synthetic Demo

## Overview
This is a standalone Streamlit demonstration of the PulseIQ Executive Company Health Scorecard.

All dashboard figures are synthetic and do not represent actual company, employee, or client information.

## Reporting period
April 2025 – September 2026

Data cutoff: 30 September 2026

## Contents
- `app.py` – Streamlit dashboard
- `requirements.txt` – Python dependencies
- `data/` – 11 synthetic CSV files

## Run locally

Install dependencies:

```bash
pip install -r requirements.txt
```

Start the dashboard:

```bash
streamlit run app.py
```

## Privacy
This package contains synthetic demonstration data only.

It does not require or connect to the production DuckDB warehouse, employee records, client identifiers, credentials, or private source datasets.
